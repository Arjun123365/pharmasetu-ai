# NESFIC 2026 — proof of work

Verified in the existing PharmaSetu AI Codex Cloud repository on **9 November 2026**. Synthetic demonstration only. No live GRD systems, patient records, paid APIs or external databases were used.

## Implemented deliverables

| Module | Working implementation |
| --- | --- |
| Executive dashboard | Calculated active SKU, usable inventory, low/out-of-stock SKU and position counts, expiry batch and pending request KPIs; availability; demand, location and category charts; critical drill-down; top-moving products |
| Demand intelligence | 12 weeks of synthetic history, product/distributor-location filters, location comparison, four-week moving-average projections, adjustable explicitly simulated seasonal uplift |
| Inventory management | 30 fictional products, dosage form/pack catalogue, 360 stock batches, six locations, search/filter, signed receipts/adjustments with mandatory reason and nonnegative balance validation, local persistence and audit history |
| Stock-out early warning | Final-four-week daily demand, usable stock coverage, Critical/Warning/Healthy boundaries, location lead times, filters, explanations and CSV |
| Expiry monitoring | Expired identification, cumulative 30/60/90-day windows, packs at risk, within-SKU/location FEFO recommendations, expired-stock exclusion from usable inventory |
| Smart replenishment | Lead/safety controls, visible target and reorder breakdown, approved incoming deduction, duplicate open-request prevention, Draft/Pending Approval/Approved simulation |
| Reports and analytics | Five report types, CSV generation, distributor summaries, management summary and print styling |

All navigation is internal React state. Responsive desktop/tablet/mobile CSS, visible demonstration notices, reset confirmation, useful empty states, named inputs and notification/error messaging are implemented. Recharts visualisations support tooltips. Storage errors produce a visible session-only warning. Netlify configuration is supplied.

## Actually executed

| Command / check | Observed result |
| --- | --- |
| `npm install --cache .npm-cache --no-audit --no-fund` | Passed after moving the unwritable default cache into the repository's ignored cache directory |
| `npm ci --cache .npm-cache --no-audit --no-fund` | Passed: reproducible installation from committed lockfile, 163 packages installed |
| `npm run build` | Passed: TypeScript compilation and Vite production bundle; charts/icons split into separate chunks; no chunk-size warning in final build |
| `npm test` | Passed: **11 tests, 1 test file**, Vitest |
| `npm run test:browser` against Vite dev server | Passed: seven-module navigation, product/location filters, invalid negative adjustment rejection, stock receipt, audit persistence after reload, request status workflow, CSV download, reset cancel/confirm, 390px mobile navigation/no horizontal page overflow, no browser console/page errors |
| `APP_URL=http://localhost:4173 npm run test:browser` against `npm run preview` | Passed on the final production build, including CSV content validation, print action invocation, print-media PDF rendering, and the same workflow regression above |
| Desktop and mobile screenshots | Generated by browser test and visually inspected (1440px desktop and 390px mobile) |
| `git diff --check` | Passed before delivery |

The 11 unit tests exercise complete seed structure, expiry-day boundaries and expired stock exclusion, immutable stock receipts and audit events, negative/fractional/zero/reasonless movement rejection, exact-zero balances, last-four-week daily demand, lead-time and buffer risk boundaries, replenishment rounding and clamping, approved-only incoming deduction, receipt-driven recalculation, CSV quote/newline escaping, and invalid saved data rejection.

Browser artifacts are local, ignored outputs: `test-results/dashboard.png`, `mobile.png`, `inventory-health.csv` and `management-summary.pdf`. `browser-test.mjs` is committed so checks can be reproduced; it needs Chromium and a running development or preview server. The first browser run found a missing favicon resource; a self-contained SVG favicon fixed it, and subsequent runs reported no browser errors.

## Verification limits

A native OS print dialog was not manually exercised: the browser test verifies that the print button calls `window.print` and independently renders the print CSS into a PDF. No physical printing, public Netlify site, GitHub push/PR, Firefox/Safari run, full accessibility audit, live supply-chain integration, regulatory validation, clinical validation, ML accuracy or production load testing is claimed. Tested runtime: Node 24.22.1, npm 11.9.0, installed Chromium through Playwright. Node 22 is configured for deployment but was not separately executed in this session.

Approved demo requests are incoming quantities, not receipts. No real purchase orders, stock transfers, redistribution or disposal approvals occur. Persistence is localStorage, not a secure shared database. README and roadmap describe these boundaries and the proposed 12–16-week supervised pilot.
